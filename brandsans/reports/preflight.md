# Проверки BrandSans / 20 октября 2026 — версия 1.200

PASS — Настоящие TTF и WOFF2 Regular/Medium: сигнатуры, cmap, контуры, GPOS и горизонтальные метрики совпадают при WOFF2 roundtrip. В каждом файле 321 кодпоинт, 322 глифа с .notdef: 318 видимых кодпоинтов и 3 намеренно пустых (SPACE, NBSP, SOFT HYPHEN).

PASS — Кириллица: 76 букв, включая полный русский алфавит с Ё/ё, украинские Ґ/ґ, Є/є, І/і, Ї/ї и белорусские Ў/ў. Добавлен знак №. Проверены все кодпоинты и полные фразы через HarfBuzz. Полный Unicode-блок Cyrillic не заявляется; другие кириллические алфавиты и комбинируемые знаки не включены. Покрытие: coverage.json.

PASS — Совместимость с 1.100: контуры, горизонтальные метрики и все прежние 220 кернинговых пар для 244 старых кодпоинтов совпадают с versions/1.100/fonts. Это сравнение структурных данных, а не утверждение о байтовом совпадении всего файла, поскольку таблицы шрифта расширены.

PASS — Метрики: UPM 1000; ascender 1000; descender −260; cap height 700; x-height 520; line gap 0. WeightClass 400/500, WidthClass 7, embedding fsType=0. Основные прописные и строчные проверены по реальным yMin/yMax; выносные элементы и диакритика укладываются в конверт. Цифры табличные, advance 974.

PASS — Кернинг: 427 пар в каждом начертании, GPOS + legacy kern, script cyrl. Реальный HarfBuzz kern on/off для AV, To, WA, Yo, ÁV, Tö, ТА, То, Га, УА, Гё и Ґє. В браузере измерение «То» при 80px Medium: 138.64px с кернингом и 143.44px без него. Доказательства и SHA-256: validation.json и browser-validation.json.

PASS — Визуальные пробы настоящих TTF: cyrillic-v1.200.png и specimen.png. Общая геометрия, Ё/ё, Й/й, Ї/ї, Ў/ў, выносные элементы Д/д, Ц/ц, Щ/щ, ф и украинские/белорусские строки просмотрены. История: direction-v1.100.png, comparison-v1.100.png и versions/.

PASS — Строгая типизация и production-сборка: npm run build в demo. Scoped ESLint main.tsx/vite.config.ts с --no-ignore; Prettier с --ignore-path brandsans/.gitignore. Общие настройки SCAD исключают внешний пакет brandsans, поэтому флаги необходимы. Изменения SCAD находятся вне проверенного объёма.

PASS — Edge/Chromium 155.0.4283.62, production preview: 320/360/768/1440, document scrollWidth совпадает с viewport width. Переключение веса и кернинга, русский текст по умолчанию, языковые образцы, фильтр Cyrillic (76), общий набор (321), инспектор Ё, отсутствие fallback для поддерживаемых языков, предупреждение для китайского текста, пустое состояние, reset и скачивания проверены. Отказ загрузки шрифта и Retry проверены. В нормальном сценарии нет ошибок console/page или HTTP 4xx/5xx.

PASS в проверенном объёме — Доступность: нативные контролы, имена, семантика, видимый keyboard focus и prefers-reduced-motion. Axe WCAG A/AA на 320 и 1440 — без найденных нарушений. Color-contrast остаётся incomplete для части символов и декоративного S на фоне направляющих; символы используют проверенные цветовые пары из manual-accessibility.json, декоративный S скрыт от accessibility tree. Это не сертификация доступности.
