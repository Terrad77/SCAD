# BrandSans 1.200

Оригинальный геометрический шрифт: Regular (400) и Medium (500). Расширенные прописные, прямые плечи, компактные радиусы углов, горизонтальная S, одноэтажные a/g и квадратные окончания штрихов. Вдохновение — сдержанная автомобильная геометрия 2020-х. Логотип Nissan, фирменные шрифты и сторонние контуры не использовались. Проект не связан с Nissan.

## Файлы

- `fonts/`: настоящие TTF и WOFF2, по два начертания; `brandsans.css` с @font-face и относительными путями.
- `demo/`: самостоятельный React/TypeScript/Vite-проект, lockfile, интерактивный тестер, карта символов, инспектор Unicode, ссылки для скачивания.
- `demo/dist/`: готовая статическая production-сборка. Сервировать через HTTP, включая подпапки сайта; файл index.html нельзя открывать через file://.
- `scripts/`: исходный параметрический генератор и проверки. Контуры создаются с нуля, без загрузки или модификации существующего шрифта.
- `reports/coverage.json`: полный фактический список Unicode; `validation.json`: результаты бинарных проверок и SHA-256.
- `reports/specimen.png`: растровая проба реальных TTF.
- `OFL.txt`: SIL Open Font License 1.1 для шрифтов; `LICENSE-demo.txt`: MIT для кода.

## Запуск демо

Node >=22.12. В папке demo:

```sh
npm ci
npm run dev
```

Сборка: `npm run build`. Проверка собранной версии: `npm run preview`.

## Подключение

Скопируйте папку fonts целиком и подключите `fonts/brandsans.css`. Используйте `font-family: 'BrandSans', sans-serif`, `font-weight: 400` или `500`, `font-kerning: normal`. Для точного выбора начертаний задайте `font-synthesis: none`. CSS содержит WOFF2 первым и TTF запасным источником, font-display: swap.

## Фактическое покрытие

321 Unicode-кодпоинт, 322 глифа с учётом .notdef в каждом файле. ASCII U+0020–007E (95), Latin-1 Supplement U+00A0–00FF (96), 76 кириллических букв и 54 выбранных расширения и символа:

ı Ł ł Œ œ Š š Ÿ Ž ž ƒ ˆ ˇ ˘ ˙ ˚ ˛ ˜ ˝ – — ‘ ’ ‚ “ ” „ † ‡ • … ‰ ‹ › ⁄ € ™ ₽ ₴ ₹ ₩ ₺ ₫ ₪ ₿ ← ↑ → ↓ − ≠ ≤ ≥ №

Латиница A–Z/a–z, цифры 0–9, предсоставленные латинские акценты Latin-1, пунктуация, математические знаки, стрелки. 14 валютных символов: $ ¢ £ ¤ ¥ ₩ ₪ ₫ € ₴ ₹ ₺ ₽ ₿. Пробел, NBSP и мягкий перенос учитываются в покрытии и намеренно не имеют видимых контуров. Контрольные ASCII-символы не включены.

Полный машиночитаемый перечень с именами Unicode — reports/coverage.json. Полный Latin Extended-A не заявляется. Поддержаны русский, украинский и белорусский алфавиты. Полный блок Cyrillic Unicode и другие кириллические алфавиты не заявляются. Греческого, арабского и комбинируемых диакритических знаков нет. Нормализуйте текст в NFC (`text.normalize('NFC')`), чтобы использовать предсоставленные акценты. Демо предупреждает о неподдерживаемых символах; они отрисовываются запасным шрифтом.

## Метрики и кернинг

UPM 1000; cap height 700; x-height 520; hhea и typo ascender 1000; descender −260; line gap 0. Основные прописные выровнены по baseline 0 и cap height 700; основные строчные — по x-height 520. Контуры акцентов и выносные элементы входят в общий вертикальный конверт. Цифры табличные, advance 974 во всех начертаниях. У остальных глифов собственные advance/sidebearing.

427 явных пар в каждом начертании, включая варианты с акцентами. GPOS kern для современных движков и legacy kern для старых приложений. Примеры: AV −70, To −60, WA −55, ÁV −70; То −60, Га −70, УА −65, Ґє −55. Реальное применение проверяется HarfBuzz при включённом/выключенном kern. Лигатур, вариативных осей, курсива, вертикальной верстки и ручного TrueType hinting нет. Шрифт ориентирован на заголовки и фирменные интерфейсы; мелкий кегль и печать требуют отдельных проб.

## Воспроизводимая сборка шрифтов

Python 3.12+:

```sh
python -m pip install --target .tools -r scripts/requirements.txt
python scripts/build_fonts.py
python scripts/validate_fonts.py
```

Для растровой пробы дополнительно нужен Pillow. После пересборки скопируйте fonts/brandsans.css и reports/coverage.json в соответствующие папки demo/public и обновите архивы. Проверки включают cmap, реальные контуры всех видимых символов, границы метрик, вес, одинаковые ширины цифр, эквивалентность TTF↔WOFF2, HarfBuzz для каждого кодпоинта и kern on/off.

Инструменты: fontTools FontBuilder для настоящих таблиц TrueType; feaLib для GPOS; Brotli/WOFF2; Shapely для объединения оригинальной геометрии. Документация: https://github.com/fonttools/fonttools/blob/main/Lib/fontTools/fontBuilder.py и https://fonttools.readthedocs.io/en/latest/feaLib/index.html.

## Браузерные проверки

Сначала запустите production preview на порту 4173. Из корня пакета:

```sh
node scripts/check_browser.mjs
```

Зависимости Playwright и axe уже включены в demo/package.json. На Windows используется установленный Edge. На другой системе установите Chromium через `npx playwright install chromium` в demo. При необходимости задайте BRANDSANS_BROWSER=chrome или msedge. Скрипт проверяет адаптивность, управление, загрузку обоих webfonts, скачивания, отказ/восстановление и axe. Артефакты — reports/browser-validation.json и снимки в reports.

Предпубликационный отчёт: reports/preflight.md. Проверка не заменяет испытания на реальных устройствах и в печати.

## История: переработка 1.100 по визуальному референсу

19 октября 2026: расширены пропорции прописных и цифр, построены прямые плечи и компактные скругления, перерисованы S/s, уточнены A и R, усилены штрихи. Кегель не растягивает готовые контуры: расширение выполняется до построения штриха, чтобы сохранять толщину вертикалей и горизонталей. Регулярный штрих — 96, Medium — 124 UPM. Метрики сохраняются в обоих начертаниях. WidthClass 7 (expanded).

Референс использован для выбора общих пропорций; логотип не трассировался. Проба из настоящих TTF: reports/direction-v1.100.png. Сравнение с первой версией: reports/comparison-v1.100.png. Предыдущие шрифты и исходный образец сохранены в versions/1.000/. Полное покрытие остаётся 244 кодпоинта, кернинг — по 220 пар.

## Кириллица в версии 1.200

Добавлены 76 букв: русский алфавит А–Я/а–я и Ё/ё, а также Ґ/ґ, Є/є, І/і, Ї/ї и Ў/ў. Диапазоны: U+0410–044F; U+0401/0451, U+0404/0454, U+0406/0456, U+0407/0457, U+040E/045E и U+0490/0491. Дополнительно включён знак № U+2116. Общий набор — 321 кодпоинт.

Прописные и строчные Б/б, Д/д, Ж/ж, И/и, Л/л, Ф/ф, Ц/ц, Ч/ч, Ш/ш, Щ/щ, Ъ/ъ, Ы/ы, Ь/ь, Э/э, Ю/ю и Я/я построены в той же геометрии. Ё/ё, Й/й, Ї/ї и Ў/ў имеют собственные контуры диакритики. Контуры, ширины и существующие 220 кернинговых пар всех прежних 244 кодпоинтов сохранены — это проверяет scripts/validate_fonts.py сравнением с versions/1.100/fonts.

Новые пары доводят суммарное число до 427 на начертание. GPOS содержит script cyrl; HarfBuzz и браузер проверяют реальное включение кернинга для кириллицы. Кириллическая проба из TTF: reports/cyrillic-v1.200.png. В демо добавлены языковые примеры и фильтр Cyrillic.

Чтобы обновить установленную версию, переустановите оба файла TTF из fonts и перезапустите программу. На сайте замените файлы WOFF2/TTF новыми и обновите страницу. Имя семейства и значения font-weight 400/500 сохранены, CSS-подключение менять не нужно.
