# v0.13.5 local review exports

An author can inspect a project in Overview and download its saved script or review snapshot without opening the filesystem or running the CLI. This increment prepares local material handoff; it is not the future selected-revision publication package.

GET /api/projects/:id/export requires the existing local session/Origin protections, a supported format (script or snapshot) and the displayed 64-character readVersion. ProjectReader validates a stable snapshot, compares its identity with the requested version, captures raw allowlisted files again and requires the same identity before building the response. A changed project returns VIEW_CHANGED. The endpoint has no write/generation path and rejects POST. Existing path/symlink and snapshot safety checks apply.

Markdown reuses the documentary script renderer, preserving knowledge labels and claim/hypothesis/uncertainty/contradiction/constraint references. A review header records project/snapshot identity, saved audit verdict, audit integrity and artifact freshness; missing verification is UNKNOWN. It does not label the script approved.

JSON schema scad.review-export.v1 contains file statuses, production qualifications, the saved audit verdict and original UTF-8 contents of the reader's allowlisted material files as strings. Null identifies missing files. Unknown fields and original formatting remain inside those strings. Approval/run receipts, arbitrary output files and configuration files are outside the allowlist. This is not a restorable backup; there is no import endpoint.

Incomplete PUBLISHING states and corrupt/unreadable saved files block exports. Missing materials are allowed in a review snapshot, explicitly marked; a missing script disables Markdown. Stale and UNKNOWN findings are preserved, never promoted to PASS. Downloads do not bind or create human approvals. Inputs above 12 MiB or encoded content above 24 MiB are refused. Browser filenames use a bounded ASCII identifier, never an arbitrary path.

The React panel disables duplicate requests, announces preparation, displays persistent errors and supports retry after refresh. It requests the exact displayed version. Download copy says requested rather than claiming the browser saved the file. Blob URLs are revoked after 30 seconds or on unmount; a late response after navigation cannot initiate a download. Overview cleanup also stops obsolete run polling/details roots when returning home.

Exclusions: new LLM generation, automatic regeneration, publication approval/upload, exact final-video chapter timestamps, subtitles, Gemini analysis, accounts, Supabase and performance guarantees. See workspace-preflight.md for actual validation evidence.
